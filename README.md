# Valcrest Integreated Synergy Limited

Corporate website built with React, TypeScript, Vite, and Tailwind CSS.

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Deploy to Vercel

Import `https://github.com/devjosh005/valcrestsynergy` in Vercel. The repository includes the required Vite build settings and SPA route fallback in `vercel.json`; no environment variables are required.
